# Code of conduct

Project spaces should be useful and safe for technical collaboration.

## Expected behavior

- Discuss code and decisions without attacking people.
- Give specific, reproducible feedback.
- Respect boundaries and stop unwanted contact.
- Do not publish another person's private information.
- Credit work and correct attribution mistakes.

Harassment, threats, sexual attention, discriminatory remarks, and sustained disruption are not accepted.

## Enforcement

Report conduct problems privately to a maintainer. Include links or screenshots when possible. Maintainers may edit or remove content, close threads, limit participation, or ban an account. They should avoid handling a report when they are personally involved and should keep reporter details private except where disclosure is required for safety or law.

This policy applies in the repository, issue tracker, review threads, release channels, and project events.
